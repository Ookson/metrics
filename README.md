# Каталог файлов

Учебная программа для работы с каталогом файлов: формирование каталога, вывод списка файлов, удаление файлов, созданных раньше заданной даты, и поиск файла с наибольшим количеством обращений.

Проект содержит две версии программы:

| Версия | Расположение | Описание |
|---|---|---|
| Линейная | `linear/linear_version.py` | Весь код в одном файле, без функций и разделения на модули |
| Модульная | `models/` | Код разделён на модули: `main.py`, `catalog.py`, `menu.py`, `models.py` |

## Требования

- Python 3.6+ (используются f-строки)
- Сторонние зависимости не требуются — используется только стандартная библиотека (`datetime`)

## Запуск

Все команды выполняются из корня проекта (папка `metrics`).

### Линейная версия

```bash
python linear/linear_version.py
```

### Модульная версия

```bash
python models/main.py
```

> Запускать нужно именно файл `models/main.py` из корня проекта — модули `catalog`, `menu` и `models` подключаются автоматически.

## Работа с программой

1. При запуске программа предложит ввести количество файлов в каталоге.
2. Для каждого файла вводятся:
   - имя файла (не может быть пустым);
   - дата создания в формате `ГГГГ-ММ-ДД` (например, `2024-05-17`);
   - количество обращений (целое неотрицательное число).
3. После формирования каталога доступно меню:

```
=== МЕНЮ ===
1. Вывод каталога файлов
2. Удалить файлы, созданные раньше заданной даты
3. Файл с наибольшим количеством обращений
0. Выход
```

- **Пункт 1** — выводит таблицу каталога: имя файла, дата создания, количество обращений.
- **Пункт 2** — запрашивает дату и удаляет из каталога все файлы, созданные раньше неё, сообщая количество удалённых файлов.
- **Пункт 3** — выводит файл с наибольшим количеством обращений.
- **Пункт 0** — завершает работу программы.
